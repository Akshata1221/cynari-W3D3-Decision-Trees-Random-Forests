# W3D3: Decision Trees & Random Forests

This repository contains the implementation for the **W3D3 AI/ML 3M Stack Assignment**, focusing on decision tree splitting dynamics (Gini Impurity & Information Gain), hyperparameter tuning for anti-overfitting, ensemble methods with Random Forests, experiment tracking via **MLflow**, and automated CIA reviews using **CrewAI**.

---

## 🛠️ Tech Stack & Tools

- **Core Frameworks:** Python, Scikit-Learn, Pandas, Matplotlib
- **MLOps & Tracking:** MLflow
- **Agent Integration:** CrewAI (CIA Full Stack Mentor Mode)
- **Testing:** Pytest
- **Version Control:** Git & GitHub
